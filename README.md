# isi.house — сайт мебельного производства (Краснодар)

Статический сайт с кинематографичным скролл-героем и минимальным API заявок.
Продакшен: https://isihouse.ru

## Структура

```
site/          готовый сайт (то, что уезжает в /var/www/isihouse)
  index.html   вся главная: разметка, стили и скрипты в одном файле
  privacy.html · personal-data.html · agreement.html   юридические страницы
  robots.txt · sitemap.xml · llms.txt                  слой машинной читаемости
  assets/      шрифты (self-hosted woff2), изображения, видео
deploy/        всё для сервера
  leads-api.py            приём заявок: JSONL + уведомление в Telegram
  isihouse-leads.service  systemd-юнит для него
  nginx-isihouse.conf     конфиг nginx (TLS, редиректы, кэш, gzip)
  deploy.sh               развёртывание одной командой
  drop-old-stack.sh       снятие предыдущей версии сайта
```

## Развёртывание

```bash
REPO=<git-url> bash deploy/deploy.sh
```

Скрипт ставит nginx и python3, выкладывает `site/` в `/var/www/isihouse`,
поднимает сервис заявок на `127.0.0.1:3002`, включает конфиг nginx и проверяет живой сайт.

## Секреты

В репозитории их нет и быть не должно. На сервере:

```
/etc/isihouse/leads.env   TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID   (chmod 600)
/etc/isihouse/nvidia.env  ключ NVIDIA для генерации медиа        (chmod 600)
```

Файл `.env` в любом виде игнорируется git (см. `.gitignore`).

## Технические решения

- Прокрутка нативная. Никаких библиотек инерционного скролла: скролл-герой построен
  на `position: sticky` и собственном rAF-цикле со сглаживанием и защитой от наложения seek-ов.
- Видео грузится как Blob (кольцо прогресса), поэтому работает на хостингах без поддержки
  частичной загрузки. Есть VP9-версия для сборок браузеров без H.264.
- На телефонах и при `prefers-reduced-motion` вместо скролл-видео показывается статичный герой;
  видео при этом не скачивается. Пять условий переключения совпадают в CSS и в JS и работают
  вживую при повороте экрана.
- Страница остаётся полной, если видео не загрузилось.
- Согласия по 152-ФЗ: чекбоксы сняты по умолчанию, факт согласия сохраняется с версией документа,
  аналитика подключается только после согласия в баннере cookies.
- Партнёрские условия не присутствуют в исходном коде страницы до отправки формы.

## Формат заявки

`POST /api/leads`

```json
{"name":"Имя","phone":"+79001112233","projectType":"kitchen","preferredTime":"day",
 "message":"текст","source":"form","consent":true}
```

Ответ `{"ok":true,"id":"..."}`. Ограничение: 5 заявок с одного IP за 10 минут.
Заявки пишутся в `/opt/isi-leads/leads.jsonl` и уходят в Telegram менеджеру.
